# Логотипы свободных зон ОАЭ

15 зон: DIFC, ADGM, DHCC — у них собственный закон о защите данных; остальные — крупнейшие зоны, где действует UAE PDPL. Полный список, эмират, режим защиты данных и источник каждого файла — в `manifest.json`.

Файлы лежат в `public/`, поэтому доступны по адресу `/logos/freezones/<файл>` без импорта.

## Фон

- `*-white.*` и `theme: "on-dark"` — светлый логотип для тёмного фона.
- Остальные рассчитаны на светлый фон. Для тёмной темы их можно сделать монохромными: `filter: brightness(0) invert(1);`.

## Источники и права

- Все логотипы взяты с официальных сайтов зон, кроме двух:
  - `difc.png` — Wikimedia Commons, CC BY-SA 4.0 (автор — Aisha Al khamiri);
  - `dafz.svg` — английская Википедия (логотип как товарный знак).
- Логотипы — товарные знаки своих владельцев. Мы с ними не аффилированы; логотипы только обозначают юрисдикцию, в которой проверяется сайт. Рядом с ними в интерфейсе нужна пометка «не аффилированы».
- Из `dhcc-white.svg` удалены служебные данные Illustrator (`foreignObject`/`i:pgf`). В SVG нет скриптов и внешних ссылок.
- KEZAD не вошёл: сайт kezad.ae не отвечал во время сбора.
